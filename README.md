<h3 align="center"> Connectra is an Innovative Android app designed to connect individuals based on their skills and learning goals. Whether you want to learn a new skill or teach someone, Connectra helps you find the right match seamlessly.</h3>

## 🌟 Features  
✔ **Search Skill Accordingly** – Connect with people based on skills you have & want to learn. </br>
✔ **Chat Support** – Text and Connect to people with desired skills. </br>
✔ **Ratings** – Choose you mentor by their Ratings and rate profiles.</br>
✔ **Verification** – Upload Certificated to verify that you excell in your skill.</br>
✔ **Interactive Profile System** – Users can create profiles showcasing their skills.  </br>
✔ **Task Scheduling** – Built-in to-do checklist to track learning progress.  </br>

## 🛠️ Tech Stack  
- **Java & XML** – For flexible, scalable UI development.  
- **Firebase Authentication** – Secure login & user management.  
- **Realtime Database** – Real-time database for storing user profiles & skill matches.
- **Firebase Storage** – Cloud Storage to store Profie Images and Certificates.
